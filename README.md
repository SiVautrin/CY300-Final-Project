# Rock, Paper, Magic

A local, two-player spell-drawing game in Python and Pygame. The project is a work in progress; gameplay classes are being built out.

## Run locally

Requires Python 3.10 or newer.

```powershell
python -m pip install -r requirements.txt
python Main.py
```

## Project files

- `Main.py` — Pygame entry point
- `Player.py` — player state
- `Spell.py` — spell and element classes
- `CombatResolver.py` — combat resolution
- `StrokeRecognizer.py` — drawing recognition
- `DrawingCanvas.py` — spell drawing input
- `Arena.py` — arena visuals
- `Game.py` — game flow

The project partners write and understand the game logic together. AI assistance is intended mainly for visual design and targeted questions.
